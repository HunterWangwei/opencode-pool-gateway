# OpenCode Pool Gateway v0.5.1

## 版本概览

本补丁版本修复账号配置可能在启动时被错误清理的问题，并改进仅 API Key 模式对 HTTP 403 与模型区域限制的判断。升级兼容现有 `data/` 目录，无需迁移。

## 重要修复

### 账号配置不再自动删除

- 移除旧版“演示账号清理”迁移逻辑。
- 程序启动时只读取账号配置，不会按 Workspace ID、Cookie、名称、账号类型或字段完整度过滤账号。
- 不再自动合并 Workspace ID 相同的记录。
- 账号仅能通过管理页面中的删除操作移除。

### 正确识别模型区域限制

- `deepseek-v4-flash` 返回 `RegionError` 时，不再判定 API Key 无效。
- `RegionError` 说明当前模型需要在 Workspace 中明确选择托管区域，是模型级限制，不代表其他模型不可用。
- 收到该错误后会确认 API Key 和对应 Go/Zen 服务已通过鉴权。
- 支持从 `/workspace/<workspace-id>/go` 等错误链接提取 Workspace ID。

### 收紧无效凭证判断

- HTTP 401 仍会判定 API Key 无效或失效。
- 明确的 `AuthenticationError` 或 `AuthError` 仍会拒绝保存。
- 普通 HTTP 403 不再被统一视为认证失败，避免将区域、模型或权限限制误判为无效 Key。

## 测试覆盖

- 启动加载时保留 API Key-only、Workspace 和字段不完整的账号。
- `403 RegionError` 确认服务权益并提取 Workspace ID。
- `403 AuthenticationError` 仍正确拒绝无效凭证。

## 升级步骤

1. 备份程序目录下的 `data/`。
2. 停止旧版本程序或 systemd 服务。
3. 使用对应平台的 v0.5.1 可执行文件替换旧文件。
4. 启动程序并确认账号池中的记录完整保留。
5. 使用 `--version` 确认版本。
