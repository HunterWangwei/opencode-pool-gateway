# OpenCode Pool Gateway v0.6.0

## 版本概览

本版本新增“账号密码登录”添加方式。用户只需填写 GitHub 账号、GitHub 密码和邮箱密码，程序会在后台运行协议脚本，取得 Account、Workspace ID 与 auth Cookie，并继续自动读取账号邮箱和本人 API Key。

该流程已在 Windows 环境完成人工全流程测试。

## 新增功能

- 添加账号页面新增第三种方式：`账号密码登录`。
- 后台按脚本原始参数协议运行：
  - `账号----密码`
  - `账号----密码----邮箱密码`
- 自动读取脚本生成的 Account、Workspace ID 和 auth Cookie。
- 自动调用现有 OpenCode 账号发现接口读取邮箱及完整 API Key。
- 发现多个本人 API Key 时，可在保存前自行选择。
- 支持优先级和凭证独立代理配置。

## 协议脚本

- 内置用户提供的原始 `opencode_auth_extractor.py`。
- 网关只负责传入参数并读取结果，不修改脚本协议和行为。
- 自动依次检测 `python3`、`python` 与 Windows `py -3`。
- Python 解释器必须能够导入 `requests`。

安装依赖：

```bash
python3 -m pip install requests
```

Windows：

```powershell
py -3 -m pip install requests
```

## 运行目录

每次协议登录都会在程序本体目录创建：

```text
temp/opencode-auth-随机字符/
```

目录中保留：

- 协议脚本副本
- 脚本生成的账号 JSON
- `stdout.log`
- `stderr.log`

文件不会自动删除，便于排查登录或字段提取问题。确认不再需要后可以手动清理。

## 数据保护

- GitHub 密码和邮箱密码不会写入 `data/accounts.json`。
- `data/`、`temp/`、本地脚本结果 JSON 和 Python 缓存不会提交到 Git。
- Account、Workspace ID、auth Cookie 与选定的 API Key 按现有账号配置逻辑保存。

## 升级步骤

1. 备份程序目录下的 `data/`。
2. 安装 Python 3 和 `requests`。
3. 停止旧版本程序或 systemd 服务。
4. 使用对应平台的 v0.6.0 可执行文件替换旧文件。
5. 启动程序并使用“账号密码登录”进行添加。
6. 使用 `--version` 确认版本。
