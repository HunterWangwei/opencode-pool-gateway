# OpenCode Pool Gateway v0.7.2

## 概览页

- 账号状态改为紧凑表格，一行显示一个账号。
- 集中展示账号类型、运行状态、Go 最高用量、Zen 状态和最近检查时间。
- 大量账号时列表独立滚动，长账号名和 Workspace ID 自动省略。
- 窄屏下自动切换为紧凑布局，详细额度继续在账号池页面查看。

## Windows 启动修复

- 修复双击程序时因 `8787` 端口占用而直接闪退的问题。
- 如果已有 OpenCode Pool Gateway 在运行，将自动打开现有管理页面。
- 如果端口被其他程序占用，将显示明确提示并等待用户关闭窗口。
