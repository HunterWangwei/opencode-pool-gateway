# OpenCode Pool Gateway v0.7.3

## 凭证自动禁用

- 上游返回 HTTP `401` 或 `429` 时，当前凭证会自动标记为已禁用。
- 禁用凭证不会继续参与网关调度，也不会被自动刷新任务使用。
- 禁用状态会保存到账号配置，程序重启后仍然保留。

## 手动控制

- 账号池卡片新增“启用/禁用”按钮。
- 手动启用后会立即重新检测凭证，确认恢复后重新参与请求调度。
