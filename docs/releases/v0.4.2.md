# OpenCode Pool Gateway v0.4.2

## 发布摘要

本版本重点完善代理能力、请求日志准确性和管理界面布局。升级兼容现有账号、登录、令牌与网关配置，无需迁移 `data/` 目录。

## 主要更新

### SOCKS5 代理

- 全局代理和单凭证代理均支持 `socks5://`。
- 支持 SOCKS5 用户名密码认证。
- 单凭证代理与全局代理同时存在时，继续优先使用单凭证代理。
- 用户名或密码含特殊字符时，应使用 URL 编码。

示例：

```text
socks5://username:password@127.0.0.1:1080
```

### 请求日志

- 支持从普通 JSON、gzip 压缩响应和 SSE 流式事件中解析用量。
- 支持 OpenAI Chat Completions 与 Responses 两种缓存字段。
- 保持 Anthropic Messages 与 Gemini `usageMetadata` 用量解析。
- 耗时根据长度显示为 `842 ms`、`3.6 秒` 或 `1 分 03 秒`。

### 管理界面

- 设置页在桌面端使用双栏布局：网关设置与监控偏好位于左侧，登录安全与程序操作位于右侧。
- 窄屏自动回落为单栏。
- 桌面端侧栏固定，底部运行状态不会随页面内容滚动。

## 问题修复

- 修复没有请求日志时页面提示 `Cannot read properties of null (reading 'length')`。
- 修复没有访问令牌时可能出现的同类空列表错误。
- 修复 gzip 或 SSE 响应成功但输入、输出与缓存 Token 显示为 `0` 的问题。

## 兼容性

- 配置格式保持兼容。
- 无需修改 `data/accounts.json`、`data/auth.json`、`data/gateway.json` 或 `data/tokens.json`。
- HTTP、HTTPS 代理配置继续有效。
- API 路由和第三方客户端接入方式保持不变。

## 升级方式

1. 备份程序目录下的 `data/` 文件夹。
2. 停止旧版本程序或 systemd 服务。
3. 使用对应平台的 `v0.4.2` 可执行文件替换旧文件。
4. 重新启动程序。
5. 使用 `--version` 确认版本。
