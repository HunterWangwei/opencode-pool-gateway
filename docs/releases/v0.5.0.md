# OpenCode Pool Gateway v0.5.0

## 版本概览

本版本新增仅 API Key 凭证接入、Go/Zen 权益探测、账号类型识别和模型级路由限制，并改进账号卡片对 API Key-only 凭证的状态表达。现有 `data/` 配置可直接沿用，无需迁移。

## 新增功能

- 添加账号支持 `Workspace + Cookie` 与 `仅 API Key` 两种方式。
- 仅 API Key 模式只显示 API Key、优先级和独立代理三个字段。
- 使用 `deepseek-v4-flash` 分别调用以下接口探测权益：
  - `POST /zen/v1/chat/completions`
  - `POST /zen/go/v1/chat/completions`
- 可从 OpenCode `CreditsError` 的付款链接中自动提取 Workspace ID。
- 账号类型细分为 Free、Go、Zen 和 Go + Zen。
- 模型窗口显示当前凭证对每个 Go/Zen 模型是否可用及不可用原因。

## 权益与路由

- Free 凭证不能用于 Go 路由。
- Free 凭证只能用于官方免费 Zen 模型。
- Zen 付费模型只会调度已开启 Zen 计费的凭证。
- Go 路由只会调度已确认 Go 权益的凭证。
- 没有符合权益的凭证时，网关返回 HTTP 402 和结构化 `CreditsError`。

## 界面改进

- 账号类型徽标移至独立元信息区域，不再与长账号名称或运行状态重叠。
- 长名称和 Workspace ID 使用省略显示，悬停可查看完整内容。
- API Key-only 凭证无法读取 Workspace 配额时显示“需 Cookie 查询”，不再误报“未开通”。
- 仅 API Key 表单使用明确的必填 API Key 提示。
- API Key-only 凭证的 Cookie 状态显示为“不适用”。

## 行为说明

- API Key 探测不会请求公开的 `/models` 目录进行验证。
- 探测请求固定使用 `deepseek-v4-flash`、单条 `.` 消息和 `max_tokens: 1`，可能产生极少量 Token 消耗。
- API Key 本身不能读取 Go 5 小时、每周、每月额度窗口或 Zen Workspace 余额；这些数据仍需要 Workspace ID 和 auth Cookie。
- API Key-only 凭证只在首次添加时探测，普通刷新不会重复产生探测请求。

## 修复

- Free 账号不再因 Zen 余额为零进入“需关注”或“用量告急”。
- 模型目录空结果统一返回 `[]`，避免前端读取空值失败。
- PowerShell 构建脚本在编译失败时正确返回失败状态。

## 升级步骤

1. 备份程序目录下的 `data/`。
2. 停止旧版本程序或 systemd 服务。
3. 用对应平台的 v0.5.0 可执行文件替换旧文件。
4. 启动程序并登录管理页面。
5. 使用 `--version` 确认版本。
