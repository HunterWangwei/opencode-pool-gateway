# OpenCode Pool Gateway v0.7.0

## 版本概览

本版本新增完整的代理池管理能力。代理池拥有独立页面，以表格展示代理地址、绑定凭证和请求统计；每个凭证通过稳定映射固定使用一条代理。

## 代理池

- 左侧导航新增“代理池”页面。
- 支持添加、编辑、删除多条代理并立即热更新。
- 表格显示：
  - 代理地址
  - 绑定凭证
  - 请求成功次数
  - 请求失败次数
- 账号池卡片显示凭证当前绑定的代理。
- 代理统计从请求日志中汇总，可跨程序重启保留。

## 固定分配

代理池按照凭证 ID 进行稳定映射：

- 同一个凭证始终使用同一条代理。
- 普通请求不会轮换代理。
- 增删代理或调整代理池顺序后会重新计算映射。

代理优先级：

```text
凭证独立代理 > 代理池固定代理 > 全局代理
```

## SOCKS5H

新增以下代理格式：

```text
socks5h://username:password@host:port
```

SOCKS5H 会将目标域名交由代理服务器解析。HTTP、HTTPS 和原有 SOCKS5 代理继续兼容。

## Zen Free 模型

以下模型现在会正确标记为 Free 可用：

- `hy3-free`
- `nemotron-3.5-lightning-free`

## Web 版本号

- 侧栏默认版本文本更新为 `OpenCode Pool Gateway 0.7.0`。
- 页面加载后继续通过 `/api/version` 显示实际构建版本。

## 升级步骤

1. 备份程序目录下的 `data/`。
2. 停止旧版本程序或 systemd 服务。
3. 使用对应平台的 v0.7.0 可执行文件替换旧文件。
4. 启动程序并进入“代理池”页面添加代理。
5. 使用 `--version` 确认版本。
